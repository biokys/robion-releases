# Robion releases

Release artifacts and the auto-update feed for the [Robion](https://robion.app) desktop app — a cockpit for Claude Code agents on macOS.
Download the latest DMG from [Releases](https://github.com/biokys/robion-releases/releases); installed apps update automatically.

- Website: <https://robion.app>
- User manual: <https://robion.app/docs/>
- What changed in each version: <https://robion.app/changelog/>
- Linux server install guide: <https://robion.app/server/>
- Questions, bug reports and feature requests: [Issues](https://github.com/biokys/robion-releases/issues)
